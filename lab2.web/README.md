```text

```
Pengerjaan

 1. Tabel Data Mahasiswa
Membuat tabel menggunakan `<table>`, `<tr>`, `<th>`, dan `<td>` serta menambahkan data mahasiswa.

 2. Struktur Tabel
Menggunakan `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, dan `colspan`.

 3. Form Registrasi Mahasiswa
Menggunakan input nama, email, password, dan tanggal lahir.

 4. Radio Button dan Checkbox
Menggunakan radio button untuk jenis kelamin dan checkbox untuk keahlian.

 5. Select dan Textarea
Menggunakan select untuk program studi dan textarea untuk alamat.

 6. Validasi Form Dasar
Menggunakan `required`, `minlength`, `min`, dan `max`.

 7. Semantic HTML
Menggunakan `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, dan `<footer>`.

 8. Multimedia
Menambahkan audio dan video menggunakan elemen `<audio>` dan `<video>`.

9. Proyek Mini
Membuat halaman biodata mahasiswa yang berisi semantic structure, tabel data, form, dan validasi dasar.
